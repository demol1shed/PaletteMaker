# CLAUDE.md

This file provides guidance to Claude Code (claude.ai/code) when working with code in this repository.

Görselden (PNG/JPEG/WebP) renk paleti çıkaran uygulama. C# / .NET 10 + Avalonia 12, arayüz **İngilizce ve Türkçe** (sistem dilini izler). Linux, Windows 11 ve Android hedeflenir. `~/CLAUDE.md` kuralları geçerlidir: yazma yalnızca bu proje dizininde (ve NuGet önbelleğinde) yapılır. Tek istisna kullanıcının onayladığı Android araç zinciridir: `android` workload'ı `~/.dotnet`, Android SDK `~/Android/Sdk`, JDK `~/.local/share/jdk-21`.

## Komutlar

```bash
dotnet build                                      # tüm çözüm (PaletteMaker.slnx; Android hariç)
dotnet test                                       # birim + arayüz yerleşim testleri
dotnet test --filter "FullyQualifiedName~Cmyk"    # tek test/grup
dotnet run --project src/PaletteMaker -- <resim>  # isteğe bağlı ilk argüman: açılışta yüklenecek dosya

# Tek dosyalı, self-contained yayın (Windows .exe Linux'tan derlenir)
dotnet publish src/PaletteMaker -c Release -r win-x64 --self-contained \
  -p:PublishSingleFile=true -p:IncludeNativeLibrariesForSelfExtract=true \
  -p:DebugType=None -p:DebugSymbols=false -o dist/win-x64      # linux-x64 için -r ve -o değişir

# Android APK (arm64, debug anahtarıyla imzalı; yalnızca kendi cihazına kurmak için)
dotnet publish src/PaletteMaker.Android -c Release -f net10.0-android -o dist/android
```

Çıktılar ~100 MB'dır (çalışma zamanı + Skia gömülü). Trimming kapalı tutulur. `RemoveNativePdbs` hedefi (csproj) yayın klasöründen NuGet'in getirdiği yüzlerce MB'lık `.pdb`'leri siler. `dist/` ve `bin/obj` git dışıdır.

### Palet algoritması (`PaletteExtractor`)
5 bitlik RGB histogramı → OKLab'da ağırlıklı k-means (k-means++, sabit tohum 12345, k = `max(48, 2×MaxColors)` yani en çok 96; çıktı deterministik) → payı gürültü eşiğinin altındaki kümeleri at (JPEG/kenar artıkları; eşik %1, `MaxColors` > 24 iken `0,25/MaxColors`, yani 48'de ≈ %0,52) → birbirine `MergeStrength`'e bağlı eşikten yakın kümeleri birleştir (açıklık farkı 0,5 ağırlıkla sayılır; eşik 0,01–0,14, varsayılan güç 0,4 ≈ 0,062) → `MaxColors` (2–48, varsayılan 10) aşılıyorsa en yakın çiftleri birleştirmeye devam. `MaxColors` bir üst sınırdır; palet daha kısa çıkabilir (çok renkli görüntüde 48 renk görmek için ton birleştirmeyi "az"a çekmek gerekir: birbirine 0,06'dan yakın renkler varsayılanda birleşir). `Extract` bir `CancellationToken` alır (k-means her yinelemede, birleştirme her turda kontrol eder); `MainViewModel` kaydırıcı sürüklenirken önceki hesabı gerçekten durdurur. Süre (masaüstü, 256 px): fotoğrafa yakın görüntüde 24 renk ≈ 150 ms, 48 renk ≈ 255 ms; en kötü durum (her piksel ayrı renk) 48'de ≈ 1,6 sn. Alfası 128'in altındaki pikseller yok sayılır. Eşik sabitleri dosyanın başındaki `const`'lardadır.

### Yerelleştirme (`src/PaletteMaker.UI/Localization`)
- Metinler `Strings.resx` (nötr = **İngilizce**) ve `Strings.tr.resx` içindedir; TR dışı her dil İngilizce görür, dil açılışta `CurrentUICulture`'dan belirlenir (çalışma zamanında geçiş yok). XAML'de `{loc:T Anahtar}` (`xmlns:loc="using:PaletteMaker.Localization"`), kodda `Loc.Get("Anahtar")` / `Loc.Format("Anahtar", args)`. `"Anahtar.Android"` varsa Android'de o kullanılır (tıkla → dokun); **bu varyant her iki `.resx`'te de olmalı** (tr'de eksikse Türkçe Android'de İngilizce görünürdü). `Strings` sınıfı yoktur; yazım hatasını `LocalizationTests` yakalar (iki dosyanın anahtar kümesi aynı, boş değer yok, yer tutucu sayısı eşit, kodda/XAML'de kullanılan her anahtar var, kullanılmayan anahtar yok).
- **Core yerelleştirmez:** `ImageLoadException.Kind` (`ImageLoadError`) taşır, `Message` nötr İngilizcedir; arayüz `MainViewModel.ErrorText(kind)` ile yerel metne çevirir. Yeni hata türü eklenirse oradaki `switch`'e ve iki `.resx`'e de eklenir.
- Android uygulama adı `Resources/values/strings.xml` (EN) + `values-tr/strings.xml` (TR) → `@string/app_name`. Uydu (satellite) kaynak derlemeleri tek dosyalı masaüstü yayında ve Android Release'te pakete girdiği doğrulandı.
- Testler: yerleşim testleri TR ve EN ile çalışır (`LocalizationTests`). **Bir Avalonia nesnesi (örn. `SwatchViewModel` → `SolidColorBrush`) yaratan test `[AvaloniaFact]/[AvaloniaTheory]` olmalıdır**; düz `[Fact]` Dispatcher'ı yanlış iş parçacığına bağlayıp sonraki headless testleri "different thread owns" hatasıyla düşürür.

### Dışa aktarma ve paylaşma
- **Core (saf, testli):** `ColorMath.ToHsl/ToOklch` + `FormatHsl/FormatOklch` (`hsl(355, 78%, 56%)`, `oklch(62.8% 0.258 29.2)`), `PaletteExport` (`HexList`, `CssVariables`, `Json`, `AndroidColorsXml`, `GimpPalette(palette, ad, sütun)`, `AdobeSwatchExchange`/`PhotoshopSwatches` (`byte[]`; `.ase`: ASEF, düz renk listesi, RGB float32 0–1; `.aco`: v1 + adlı v2 bölümü, kanal = değer×257; hepsi big-endian, ad = hex, UTF-16BE; testler küçük ikili ayrıştırıcılarla gidiş-dönüş yapar)), `PaletteCardRenderer.RenderPng` (karo ızgarası PNG; sütun `ColumnsFor`, boş hücreler açık gri). Metinler `InvariantCulture`, satır sonu `\n`; GIMP adı satır enjeksiyonuna karşı temizlenir. Testler altın metin + küçük bir `.gpl` ayrıştırıcıyla gidiş-dönüş + PNG→`PaletteExtractor` gidiş-dönüşü.
- **Resprite (Android) yalnızca `.gpl` ve kendi `.rpl` dosyasını, dosya seçiciyle içe aktarır** (Menü ▸ Palet ▸ RPL/GPL dosyası içe aktar); panoya kopyalanan metin işe yaramaz. `.rpl` belgesiz olduğu için yazılmadı. `.gpl` kaydı **tüm platformlarda `StorageProvider.SaveFilePickerAsync`** (Android'de sistem SAF penceresi, izin yok); MIME `application/octet-stream` (`text/plain` Android'de dosya adına `.txt` ekler). Resprite'ın gerçek içe aktarması cihazda denenmedi. `.ase`/`.aco` kaydı `.gpl` ile aynı yoldur (`SaveFileAsync`, MIME `application/octet-stream`); çıktı Python ile spesifikasyona göre okunup doğrulandı ama **gerçek Photoshop/Illustrator'da denenmedi**.
- **Değer biçimi:** `ValueFormat` (Rgb, Cmyk, Hsl, Oklch) başlıktaki tek `ComboBox` (`FormatBox`); `MainViewModel.FormatIndex` ↔ `ValueFormat`. `SwatchViewModel.AccessibleName` kartın tam metnidir.
- **Bildirimler:** uygulamanın kendi toast'ı (`ShowToast`) panoya kopyalamada, `App.SystemShowsClipboardConfirmation` (Android 13+, `MainActivity` atar) `true` iken gösterilmez: sistem zaten kendi "Kopyalandı" onayını verir, ikisi birden çift mesaj olurdu. Yükleme hataları (`ErrorMessage`) görsel alanı içindeki `ErrorCard`'da gösterilir (`ShowDropHint` ile ipucunun yerini alır).
- **Alt sayfa ("Paylaş ve dışa aktar"):** `MainView.axaml`'de `Root` grid'inde kaplama (`ExportSheetHost`: perde + alta oturan `ExportSheet`, tema bazlı `SheetBackground`); `MainViewModel.IsExportOpen`; perdeye dokunma, kapat düğmesi, **Esc** ve **Android Geri** (`TopLevel.BackRequested`, `OnBackRequested`) kapatır. Kopyalama öğeleri panoya, `.gpl`/`.ase`/`.aco`/PNG dosya olarak kaydeder. PNG için `App.ShareService` (`IShareService`) atanmışsa (Android) sistem paylaşım menüsü, değilse "Farklı kaydet".
- **Android paylaşım:** `AndroidShareService` PNG'yi önbelleğe (`cache/shared`, 1 günden eskiler silinir) yazar ve `FileProvider` ile (`io.github.demol1shed.palettemaker.fileprovider`, her iki manifestte `<provider>` + `Resources/xml/file_paths.xml`) `ACTION_SEND` ile verir; **ek izin yok** (varsayılan APK hâlâ izinsiz).
- **İmzalama notu:** `apksigner` aynı `file:` dosyasını hem mağaza hem anahtar parolası için verince **ardışık satırlardan** okur; bu yüzden `~/.local/share/palettemaker-signing/password.txt` aynı parolayı **iki satırda** içerir (tek satırda APK imzalama "end of file" ile `java exited with code 2` verir; AAB yolu etkilenmez).

### Kalite ve operasyon
- **CI (`.github/`):** `ci.yml` her push/PR'da `dotnet build -c Release` + `dotnet test -c Release --no-build`; `android.yml` (yalnızca Android/UI/Core yollarında değişiklik olunca) workload + SDK kurar, varsayılan ve `Store=play` **Debug** derler (yükleme/sır yok); `release.yml` `v*` etiketinde Windows/Linux tek dosyalı yayınlarını paketler, `SHA256SUMS.txt` üretir ve Release'e ekler (APK yok; Android yalnızca Play'den). `dependabot.yml` NuGet + Actions haftalık; **SkiaSharp\*/HarfBuzzSharp\* yok sayılır** (Avalonia.Skia ile aynı sürüm olmalı, elle eşitlenir), Avalonia\*/Xamarin.\*/xunit gruplanır. Actions yerelde çalıştırılamaz: komutlar yerelde doğrulandı, gerçek doğrulama push sonrası çalıştırmayla (`gh run watch`).
- **Play içi değerlendirme (yalnızca `Store=play`):** `PlayReviewPrompt` başarılı palet sayısını (`MainViewModel.PaletteLoaded`, yalnızca yeni görsel yüklemesi) SharedPreferences'ta sayar; `ReviewPolicy` (saf, `Engagement/`): ≥ 5 palet, ilk açılıştan ≥ 3 gün, son istekten ≥ 60 gün, alt sayfa/meşgul değilken. Zamanı önce kaydeder; hatalar yutulur; DEBUG'da `FakeReviewManager`. Google kota uygular, istek gösterilmeyebilir.
- **Erişilebilirlik:** etkileşimli her öğede `AutomationProperties.Name` (kartlar `SwatchViewModel.AccessibleName`, sürgüler ad + `HelpText`, önizleme, görsel alanı); görsel alanı ve kartlar `Focusable`, Enter/Boşluk ile etkinleşir, `:focus-visible` çerçevesi; bildirim `LiveSetting=Polite`, hata `Assertive`. Hata rengi tema kaynağı `ErrorText` (açık `#B3261E`, koyu `#F2B8B5`; `IndianRed` AA kontrastını geçmiyordu). `AccessibilityTests` adları, klavyeyi ve WCAG 4,5:1 kontrastını denetler. TalkBack'in gerçek davranışı cihazda denenmedi.
- **HEIC/AVIF/GIF/BMP (yalnızca Android):** `IImageTranscoder` (`MainViewModel.Transcoder`, Android'de `AndroidImageTranscoder`): Skia'nın açamadığı içerikte (`ImageLoadError.NotAnImage`) `BitmapFactory` ile çözer (önce yalnızca boyut, `ImageLoader.MaxPixels` aşılırsa reddedilir; uzun kenar ≤ ~1024'e 2'nin kuvvetiyle küçülür) ve **PNG'ye çevirir; çıktı yine `ImageLoader.Decode` içerik doğrulamasından geçer**. `EnsureSupportedName` ek uzantıları (`.heic .heif .avif .gif .bmp`) yalnızca çözücü varken kabul eder; uzantısız (content://) adlar zaten geçer. Seçici MIME listesi ve paylaşım `intent-filter`'ları genişletildi. HEIC API 28+, AVIF API 31+ (eski sürümde genel hata). HEIC/AVIF/GIF/BMP dönüşümünde EXIF yönü kaybolur (palet etkilenmez, önizleme dönük görünebilir); PNG/JPEG/WebP'de ise önizleme EXIF yönüne göre `ImageLoader.RenderOrientedPreviewPng` ile döndürülür (yön doğruysa hızlı `Bitmap.DecodeToWidth` yolu). Masaüstü davranışı aynı. Cihazda denenmedi.

### Yerleşim ve yükleme (Android ile ortak)
- **Tek görünüm, iki düzen:** genişlik 600 px'in altına inince `MainView` köke `narrow`, yükseklik 520 px'in altına inince `short` sınıfını ekler; telefon düzeni `.narrow` stilleriyle kurulur. Düzene göre değişen bir değeri (kenar boşluğu, sütun sayısı, yükseklik) öğeye yerel olarak yazma, stilde tut: yerel değer `.narrow` stilini ezer. Palet sütun sayısı `MainView.ColumnsFor` ile genişlikten hesaplanır.
- **Yükleme akış tabanlıdır:** Android seçicisi ve paylaşım `content://` verir, `TryGetLocalPath()` `null` döner. `MainViewModel.LoadAsync(ad, akışAç)` baytları `ImageLoader.ReadBounded` ile bir kez okur; palet ve önizleme aynı baytlardan üretilir. Yerel yol varsa (masaüstü) uzantı zorunludur, akışta uzantısız ad kabul edilir (`EnsureSupportedName`); içerik denetimi her iki yolda da geçerlidir.
- Görsel alanı `Tapped` ile açılır, `PointerPressed` ile değil (dokunmatikte sayfa kaydırılırken seçici açılmasın). Dar düzende dokunma hedefleri en az 40 px'tir (testle denetlenir).
- Güvenli alan (çentik, sistem çubukları): Avalonia `TopLevel.AutoSafeAreaPadding` ile ana görünümün `Padding`'ini stil önceliğinde kendisi ayarlar; `MainView`'e yerel `Padding` verme.
- Android Release paketi kırpılır (SDK varsayılanı); masaüstünde trimming kapalıdır. Debug APK hızlı dağıtıma dayanır, elle kopyalanınca açılmaz: cihaza Release derlemesi kurulur.

## Dikkat edilecekler

- **SkiaSharp sürümü Avalonia.Skia'nınkiyle aynı olmalı** (şu an 3.119.4). Core'daki `SkiaSharp` ve `SkiaSharp.NativeAssets.Linux` referansları buna sabitlenmiştir; Avalonia güncellenirse `dotnet list src/PaletteMaker package --include-transitive` ile bakıp eşitle. Yönetilen/yerel sürüm uyuşmazlığı çalışma zamanında çöker. `NativeAssets.Linux` Core'da olduğu için testler de yerel kitaplığı bulur.
- **Yerel ayar (tr-TR):** kopyalanan metinler (`rgb(...)`, `cmyk(...)`, `#RRGGBB`, yüzde) `InvariantCulture` ile üretilir; uzantı denetimi `OrdinalIgnoreCase`'dir (tr-TR'de `"GIF".ToLower()` → `"gıf"`). Testler kültürü kodla tr-TR'ye çekerek bunu denetler.
- `ImageLoader` bellek koruması: dosya ≤ 100 MB, çözünürlük ≤ ~100 MP (başlıktan okunur, çözmeden reddedilir); JPEG küçültülmüş boyutta çözülür. Önizleme `Bitmap.DecodeToWidth(…, 800)` ile açılır. Eski önizleme bitmap'i yenisi atandıktan sonra dispose edilir.
- Desteklenen biçimler yalnızca PNG/JPEG/WebP'dir; `ImageLoader` uzantıya ek olarak dosya içeriğini (`SKCodec.EncodedFormat`) de doğrular. Skia GIF kodlayamaz; testte hazır GIF baytları kullanılır.
- Avalonia 12 API'leri: sürükle-bırak `e.DataTransfer.TryGetFiles()`, pano `SetTextAsync` için `using Avalonia.Input.Platform;` gerekir. Android'de `AvaloniaMainActivity` jenerik değildir; `AppBuilder` özelleştirmesi `AvaloniaAndroidApplication<App>` alt sınıfındadır.
- CMYK profilsiz (ICC'siz) standart formüldür, yaklaşık değerdir.
